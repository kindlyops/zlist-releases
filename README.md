# zlist releases

Public release channel for [zlist](https://github.com/kindlyops/zlist).

- **Releases** hold `zlist-<version>.zip` (the app, Developer ID signed and notarized),
  Sparkle `.delta` updates, and `SHA256SUMS`.
- The `gh-pages` branch serves the Sparkle appcast at
  `https://kindlyops.github.io/zlist-releases/appcast.xml`.
